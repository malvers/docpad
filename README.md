# DOCPAD

The installable web app of DOCPAD, served at https://malvers.github.io/docpad/ — an origin of its own, so Android
installs it as a real app. The same pages run at https://docalvers.de/docpad/.

Everything here is generated by `tools/pack_web.mjs` in the DOCPAD repository: a password page, a service worker,
the app manifest and icons. The calculator itself is an encrypted bundle in Supabase Storage; it opens only with the
key that the password unlocks. Please do not edit these files by hand.
